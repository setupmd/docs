### Downloading using CLI

If you don't have access to a web browser on your server, you can use command line tools such as `curl` or `wget` to download the jar files directly to your server.

Example formatting for paper would be.

```bash
...

curl -o paper.jar https://jar.setup.md/download/paper/latest/latest

# OR

wget https://jar.setup.md/download/paper/latest/latest --content-disposition

...
```

By adding the `--content-disposition` we're preventing the downloaded file being an extension-less file called `download`.

To confirm the file has downloaded correctly you can use the `ls -al` command to display the contents of your current folder.

```bash
...

root@vps:~/minecraft-server-folder# ls -al
total 41348
drwxr-xr-x 2 root root     4096 Jul  9 16:59 .
drwx------ 7 root root     4096 Jul  9 16:59 ..
-rw-r--r-- 1 root root 42329978 Jul  9 08:07 purpur-1.19-1708.jar

...
```
